# Personalized-Retension-Engine-for-E-commerce-Growth
"Intelligent Growth &amp; Personalization Engine" Developed a Hybrid Recommender System (SVD + NLP) integrated with an Uplift Modeling strategy to boost retention for a 100k+ transaction e-commerce dataset. Created a prescriptive dashboard that recommends both products and targeted marketing interventions.



Primary Objective: Increase Customer Lifetime Value (CLV) by 10% through personalized recommendations.

Secondary Objective: Reduce Marketing Waste by identifying "churn-prone" users who actually respond to discounts vs. those who don't.

The KPI: Conversion Rate (CVR) and Mean Average Precision (MAP@K) for the RecSys.
